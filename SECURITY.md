# Security policy

agent-bridge is experimental. Security reports are welcome for the current
default branch. There is no promise of support for older revisions.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting page:

<https://github.com/scotchua/agent-bridge/security/advisories/new>

Include the affected revision, platform, a minimal reproduction, impact and any
suggested mitigation. Minimize sensitive data. Do not upload credentials,
tokens, private keys, real provider configuration, raw consultation history or
raw logs. Use synthetic examples and redact local usernames and paths.

Private reporting must be enabled by the maintainer. If the link is unavailable,
do not post vulnerability details publicly. Use the **Request a private reporting
channel** issue template, then wait for a private channel.

For ordinary bugs without security impact, use the bug-report template. The
same rule applies to attachments: share only the minimum synthetic,
non-sensitive information needed to reproduce the problem.
